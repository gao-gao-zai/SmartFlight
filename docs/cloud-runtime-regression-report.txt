复查结论与最终修复
这些是修复类别；测试中的覆盖变体不计为独立 bug。

1. 事件队列、计时和服务生命周期
- ForegroundProbeTick、TemporaryDisableExpired 也携带代次，旧事件不能清空新任务引用。
  离开/息屏 Due 继续使用 WIP 的令牌和单调时钟截止时间。
- Due 在执行前先让已经排队的前台、规则、设置、屏幕和网络变化得到处理。
  覆盖到期事件先入队、短暂返回联网应用再离开的场景；旧倒计时不能沿用。
- 已接受的前台切换历史可以取消/重建计时，不再被更新的轮询缓存抹掉。
  零延迟或黑名单立即断网仍须重新读取当前前台证据。
- 重复 start 不再反复重置计时。生命周期代次隔离旧 collector 和环境监听器，
  快速 stop/start 不会由旧 Stopped 把新运行状态置为停止。
- stop 的 acknowledgement 在清理失败时也能完成。
- 执行器不可用导致离开动作暂停时，保留待确认的离开意图，恢复确认后可重建计时。

2. 前台证据和未知状态
- 复查并保留 WIP 的源缓存隔离、声明 Activity 校验、UsageStats 生命周期和未知语义。
- 检测器增加可注入的系统查询/时钟边界；JVM 测试运行生产检测代码，
  不以平行实现的自制状态机代替生产路径。
- 覆盖联网应用长留、Dialog/IME/SystemUI 候选、真实应用切换、同包 Activity 切换、
  pause/stop、权限撤销、空查询、SecurityException、时钟回拨和源模式切换。
- 未知不被当成离开：取消待执行的离开计时并保留规则历史。
  后续确认仍处于非联网应用，会重新开始完整倒计时；确认回到联网应用则取消。
  未知不是永久联网规则；没有有效前台证据时也不能安全地凭空推断已离开。
- 修正原 androidTest 的过时断言：UsageStats 权限丢失应返回 null。

3. callback 隔离和网络读回
- 回调持有不可变的注册身份和自己的监听器；旧 callback/receiver 不能调用新监听器。
  重注册会清理旧注册，注册失败清理已建立的部分注册。
- callback 只排队，不提前覆盖快照；实际 Coordinator 测试验证外部变化比较仍拿得到旧快照。
- 增加 mobile_data 全局设置观察入口，弥补 Wi-Fi 为默认网络时可能没有默认网络回调的问题。
  OEM/双卡设置键或平台拒绝注册的情况仍需真机确认；失败会记录警告。
- 被动读回与完整网络动作共享事务，包含读、写、恢复、快照发布和日志；
  旧被动读结果不能在较新动作后覆盖 UI。

4. 超时、取消、恢复记忆和 UI
- Root/Binder 阻塞调用放入可取消等待的守护任务。取消不会等待一个卡住的同步调用返回，
  迟到结果不能恢复已取消的调用；Root 取消同时关闭会话。
- Shizuku 绑定取消会解绑，迟到或重复连接回调不能重复恢复 continuation。
- Root 输出的单行长度和总输出（含换行）都有上限，避免 readLine/空短行突破输出上限。
- 开启飞行模式前先持久化移动数据恢复记忆，取消发生在写后、读回前也不会丢失。
  已经处于飞行模式且没有记忆时，不把当前移动数据状态冒充为切换前状态。
- 取消将实际状态置为未知，并保留失败动作和触发来源；被动权限刷新不能把它改成成功。
- 移动数据写失败时 UI/日志显示请求的动作，状态字段仍显示实际读回值。
- 保留并验证 WIP 的写后有界重试读回、未知/失败恢复不报成功、保留恢复记忆等逻辑。

回归覆盖证据
- ForegroundEvidenceRegressionTest：直接运行 Accessibility/UsageStats/Hybrid 生产检测器；
  Android 查询、PackageManager 声明解析和时钟使用可控输入。这是 JVM 模拟，不是真机窗口事件。
- RuntimeEventLoopRegressionTest：使用实际 Coordinator 事件循环、实际 Handler/Scheduler，
  以虚拟时间和可暂停的环境边界制造 Due 排队、快返再离开、亮屏、设置取消、源丢失、
  权限/执行器恢复、规则跟随、服务重启和外部网络变化。未替换事件循环本身。
- RuntimeTaskSchedulerTest：陈旧 probe/expiry/Due、取消、替换、单调截止时间和快速切换。
- NetworkControlTransactionTest：暂停旧被动读，确认完整动作须等它发布后执行。
- ExecutorProbeServiceTest：实际 action/probe/snapshot 链路的延迟读回、失败、未知、取消、
  恢复记忆和并发动作。执行器仍是 JVM 假实现，不能证明真实 Root/Shizuku 权限和 Binder 行为。
- BoundedProcessExecutionTest：假进程以及真实云端 sh 的输出/退出、继承管道截止时间，
  Root 会话输出上限和不可协作阻塞任务的取消。云端 sh 不等于 Android su。

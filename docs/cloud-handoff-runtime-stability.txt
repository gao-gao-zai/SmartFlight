Implemented drafts:
- Accept declared Activity evidence rather than foreign dialog/IME/overlay
  candidates; isolate source caches and reconcile Accessibility with UsageStats.
- Treat missing foreground evidence as unknown while preserving prior rule
  history; handle source loss, lifecycle invalidation, and quiet Activities.
- Give disconnect tasks generations and monotonic deadlines; recheck foreground
  on expiry; rebuild screen-off tasks on restart and relevant settings changes.
- Verify network state before and after writes; preserve unknown/failed restore
  state; serialize actions and bound process execution/output collection.
- Forward network callbacks to the runtime event queue without overwriting the
  previous snapshot before external-change comparison.

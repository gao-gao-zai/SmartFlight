发行说明草稿
- 修复前台应用检测把非 Activity 覆盖窗口、未知状态和源断连当成应用离开的风险。
  联网应用长留不会仅因证据过期触发断网；真实离开仍按规则和完整倒计时判断。
- 修复快捷规则透明编辑器暂停底层 Activity 后丢失前台证据的问题；真实切换、停止或权限失效仍清除证据。
- 修复旧 probe / 到期事件影响新计时、快速返回再离开沿用旧截止时间、重复启动重置计时等竞态。
- 修复旧网络回调跨注册生效、被动读回覆盖新动作快照，以及取消后恢复记忆或 UI 状态不准确的问题。
- 强化 Root / Shizuku 阻塞等待、取消和输出边界；增加 Wi-Fi 下移动数据设置变化的观察入口。
